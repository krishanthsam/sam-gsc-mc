# Third-party notices

Sam GSC MCP is an independent, rewritten server that brings together the feature sets of three
open-source Google Search Console MCP projects. Thank you to their authors.

| Project | Author | License | What it inspired here |
|---|---|---|---|
| [AminForou/mcp-gsc](https://github.com/AminForou/mcp-gsc) | Amin Foroutan | MIT | OAuth + service-account auth, property/sitemap management, advanced analytics, period comparison, batch URL inspection, destructive-operation safety flag, `get_capabilities`, `reauthenticate`, SEO skills (weekly report, cannibalization, indexing audit, content opportunities), Docker/SSE |
| [surendranb/google-search-console-mcp](https://github.com/surendranb/google-search-console-mcp) | Surendran B | MIT | Default property via env, dimension/metric discovery tools, `summary_only`, regex filters and `googleNews`/`discover` types, skills library + `skill_read`, skills as MCP resources, workflow prompts, tool annotations, guided error messages, interactive setup recovery, update checks |
| [metehan777/google-search-console-mcp](https://github.com/metehan777/google-search-console-mcp) | Metehan Yesilyurt | No license file published | Tool ideas only (no code reused): site summary vs previous period, quick URL status, index-coverage and mobile-issue reports, direct URL submission (implemented here with the official Indexing API) |

Portions of the design derive from the MIT-licensed projects above, whose notices follow.
